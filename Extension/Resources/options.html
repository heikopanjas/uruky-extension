Startpage for Safari

Safari has no API for setting a custom search engine. This extension intercepts navigations to the engine Safari is configured to use and rewrites them to Startpage. Some traffic still reaches the origin engine before the redirect fires, and Safari's address-bar suggestions cannot be intercepted at all.

Engines to redirect

Enable only the engine you have actually set as Safari's default. That confines the unavoidable pre-redirect leak to a single provider.

Startpage preferences token

Optional. Copy the prfe value from startpage.com/do/settings to carry your Startpage settings on the query string. Unlike the settings cookie, this survives Private Browsing.

Redirect mechanism

Slower, with a brief flash of the origin engine. Turn this on only if redirects have stopped working after a Safari update.
